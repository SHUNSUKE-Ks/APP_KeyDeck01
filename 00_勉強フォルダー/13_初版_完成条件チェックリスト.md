## 章ごとの完成条件（第1〜5章）

- [ ] 説明は画面で観測できる変化から始まり、コード前の長文になっていない。
- [ ] 実在するソースの絶対パスと関数名を示している。
- [ ] コード block は1関数または小さな分岐に絞り、処理量ごとのコメントを持つ。
- [ ] 短縮・置換したコードには「説明用に簡略化」と明記している。
- [ ] 関数カードに、役割／呼ばれる場面／入力／処理順／出力／失敗時／関連関数／たとえがある。
- [ ] 操作前→コード→操作後の図があり、前後は同じ操作の実スクリーンショットである。
- [ ] 注釈は HTML の重ね書きレイヤーであり、元画像・元コードを改変していない。
- [ ] コード block の下に、上から下へ追う主フローがある。
- [ ] 左右の枝は必要な説明だけで、各側最大2本である。
- [ ] 図のノードから、詳細ページのアンカーへ遷移できる。
- [ ] 章末問題があり、解答は次ページに分離されている。
