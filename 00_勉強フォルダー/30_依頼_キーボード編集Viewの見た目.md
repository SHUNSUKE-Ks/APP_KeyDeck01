# 依頼: キーボード編集画面の「見た目」を作ってください

## 何を作るか
iPad を左手デバイス（TourBox や Stream Deck のようなもの）として使うアプリがあります。
その**ボタン割り当てを見て・選んで・編集する画面**の見た目を作ってください。
中身の処理はあとで別の人がつなぎます。今回は**見た目と触り心地だけ**です。

参考にしたいのは、TourBox の Guide 画面の見せ方です。
- 中央に機器の絵がある
- 周りに部位ごとの説明パネルがある
- 絵とパネルが線で結ばれていて、どのボタンが何をするか一目で分かる

これをそのまま真似る必要はありません。「今どきの、触って気持ちいい編集画面」として、あなたが良いと思う形を提案してください。

## 画面でできること（見た目で表現すればよい）
1. **部品を見る。** 機器には次の部品があります。
   - 回すダイヤル（大・小の2つ）
   - 十字キー
   - 修飾キー（押している間だけ、他のボタンの役割が変わる）
   - 大きいボタンと小さいボタンがいくつか
   - セット切替ボタン
2. **部品を選ぶ。** 部品をタップすると、その部品の割り当てが編集パネルに出る。説明パネル側をタップしても同じ部品が選ばれる。
3. **割り当てを変える。** 1つの割り当ては「表示名」と「動作」でできている。動作の種類は次の4つ。
   - キーの組み合わせ（例: Ctrl+Z）
   - 文字の入力
   - 押している間だけ別の割り当てに切り替える
   - セットを切り替える
   ダイヤルは「左回し」と「右回し」の2つの割り当てを持つ。
4. **セットを切り替える。** 作業ごとの割り当てセット（例: 基本／ページ／レイヤー／生成／保存）を切り替えると、全部の割り当て表示が入れ替わる。
5. **修飾中を確かめる。** 修飾キーを押している間の割り当てを、プレビューで確かめられる。
6. **押した感触がある。** ボタンを押したら沈む、光る、などの反応を返す。ダイヤルは指やマウスで回せて、目盛りごとに反応する。

## 条件
- **HTMLファイル1つ**で動くこと。CSS と JavaScript はファイルの中に書く。
- **外部ライブラリ、フレームワーク、CDN は使わない**（あとで素の HTML/JS の本体に移植するため）。フォントも端末にあるものを使う。
- **暗い配色を既定**にする（白い画面は苦手です）。明るい配色は切り替えで出せればよい。
- **iPad の横向き（1180×820 くらい）をタッチで操作**できること。PC のマウスでも操作できること。
- 割り当てのデータは、スクリプトの先頭に**1つのオブジェクト**としてまとめて置く。中身は架空のもの（漫画制作アプリのショートカットを想定）でよい。見た目はそのデータから描くこと（あとでデータを差し替えるため）。
- 実際のキー入力、通信、保存はしない。

## デザインの幅を見たいので
**方向性の違う案を3つ**、同じ HTML の中で切り替えて見られるようにしてください。
例: 機器の絵＋引き出し線型／カードを並べる型／円形メニュー型。この3つに縛られなくてよいです。

## 納品してほしいもの
1. HTML ファイル1つ（3案を切り替えられる）
2. 短いデザインメモ（Markdown）
   - 3案それぞれの狙い
   - あなたが一番良いと思う案とその理由
   - 色、角丸、影、動きの長さなどの決めごと（CSS変数の一覧）
   - ボタンの状態の一覧（通常／押下中／選択中／修飾中／空き）
   - iPad で指が届く範囲について考えたこと
