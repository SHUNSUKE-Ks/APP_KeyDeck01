# このフォルダーについて

**HUB（PC側の編集画面一式）のUI向上のための参考サンプル画像を置く場所。一時的なフォルダー。**

## 置いてよいもの
- 気に入っている他アプリ・他画面のスクリーンショット（配色・レイアウト・触感の参考）
- 手描きのラフ・構図メモ画像

## 運用ルール
- 画像そのものはAIの記憶に残らないため、**置いたら次のセッションで即テキスト化（パーツ辞書化）する**。
  以後はそのテキストを読み、画像ファイルは参照用に残すだけにする。
- 採用が決まった参考は、`00_勉強フォルダー\32_キーボード編集View_デザインメモ.md` のような
  デザインメモ（CSS変数・状態一覧など）に落とし込んでから、このフォルダーへの依存を切る。
- 作業が一段落したら（採用素材をテキスト化・設計書に反映し終えたら）このフォルダーは削除してよい。
