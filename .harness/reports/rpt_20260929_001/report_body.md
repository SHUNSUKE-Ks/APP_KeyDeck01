## 依頼の形のままではぶつかるところ

依頼ではパンもズームも「縦ドラッグ」なので、1マスの上では見分けられない。
回転（円をなぞる）もパンと混ざる。そこで**指の本数と時間で分けた**:

| 操作 | 見分け方 | 出る判定（将来の位置IDの候補） |
|---|---|---|
| パン | 1本指ですぐ動かす | `PAN_N` `PAN_E` `PAN_S` `PAN_W` |
| ズーム | 2本指でつまむ／広げる（広げる＝イン） | `ZOOM_IN` `ZOOM_OUT` |
| 回転 | 2本指でひねる | `ROT_CW` `ROT_CCW` |
| 傾け | 長押し（0.5秒・枠が黄色くなる）してから動かす | `TILT_N` `TILT_E` `TILT_S` `TILT_W` |
| 左右ボタン | 左右の端の帯（幅22%）を動かさずに短くタップ | `SIDE_L` `SIDE_R` |

どれにも当たらずに離したら「なし」。
**段階2にしても不変条件は変わらない**: 端末が送るのは上の位置IDだけで、何が起きるかは Hub の JSON が決める（二層ラジアルと同じ形）。

## 作ったもの

**`/lab/multigesture`**（`static/lab_multigesture.html`）。ナビの「実験」からも開ける。

```
iPad で開く   http://<PCのIP>:8770/lab/multigesture   （トークン不要。何も送らないため）
```

- **お題モード**: 選んだ操作 ×（既定4回）をランダムな順に出す。やった結果が ○／× で出て、**取り違え表**（行＝お題・列＝判定）と「混ざった組み合わせ（多い順）」が溜まる
- **自由モード**: お題なしで慣れる。判定・指の本数・判定までの時間・動いた距離が出る
- **積む数を変えられる**: 5種類の操作をそれぞれ外せる。外すとその判定は出なくなる（例: 傾けを外すと、長押しからのドラッグもパンになる）。**「何個まで積めるか」はこれで比べる**
- **マスの大きさ**: iPad 12.9 横の1区画（114×109）／2×2／3×3／iPhone 7 の1マス（62×62）
- **しきい値**: 動いたとみなす距離・向きを決める距離・長押しの時間・タップの長さ・端の帯の幅・つまみ量・ひねり角を画面で変えられ、各記録に残る
- **書き出し**: JSON をコピー／保存（端末の情報・各試行の判定・時間・距離・どちらと迷ったかの差つき）。記録はこの端末のブラウザにだけ残る
