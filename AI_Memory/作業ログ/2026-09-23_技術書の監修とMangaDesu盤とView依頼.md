## この回で分かった、次の人に効く事実

- **レイヤーは keymap ごと。** 別の keymap（ダイヤル・別の区画）には波及しない
- **`keymap.switch` と `layout.switch` は別物。** 前者は split 専用
- **`none` の action はラベルを描かない**（`components.js` が空扱いにする）。
  札として文字を出したいときは、自分の画面への `layout.switch` にすると押しても何も起きずに文字が出る
- **キーは `label` と `action` しか持てない**（`deny_unknown_fields`）。色もアイコンも付かない。
  Deck のタイルだけが `icon` を持つ
- **単発の `--screenshot` は iframe を描かない。** 画面の撮影は CDP で撮り、撮れた絵を必ず目で見る
