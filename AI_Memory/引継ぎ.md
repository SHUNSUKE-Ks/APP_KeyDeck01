## 1. 最初に知っておくこと

- **Hub は `start_hub.cmd` から起動する**（`cargo run -p proto-hub`。ソースを変えていれば作り直してから起動）。exe を直接叩くと古いまま
- **token は起動のたびに変わる。** 端末は PC のトップ画面の「QR」ボタン（変更が無いときの保存ボタン）から読み直す
- **`devices/devices.json`・`apps/apps.json` は起動時にだけ読む。** 書き換えたら Hub を再起動
- **本物の Hub（8770）で端末のボタンを押すと、PC に本当にキーや起動が飛ぶ。** 試すときは利用者の画面が変わっても困らないときに。押さなかった確認は「押していない」と書く
